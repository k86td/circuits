Aide

Construire un circuit

  • Ajouter un composant : glissez-le depuis la palette, ou cliquez-le puis cliquez sur le canevas (R pour pivoter avant de poser, Maj pour en poser plusieurs).
  • Relier : glissez depuis un terminal (petit cercle rouge = non connecté) jusqu'à un autre terminal ou point de grille. Un fil qui touche un terminal ou l'extrémité d'un autre fil est connecté.
  • Outil Fil (W) : glissez n'importe où pour tracer un fil.
  • Modifier : cliquez un composant pour voir ses propriétés. Double-clic pour éditer sa valeur. R pivote, Suppr efface, Ctrl+D duplique, Ctrl+Z annule.
  • Interrupteur : cliquez dessus pour l'ouvrir / le fermer.
  • Vue : molette pour zoomer, glisser le fond pour déplacer, F pour ajuster.
  • Panneaux : 1, 2 et 3 masquent / affichent la palette, les propriétés et l'oscilloscope.

Simuler

  • Espace lance / arrête. La vitesse règle le rapport temps simulé / temps réel : ralentissez pour observer un RC rapide ou un signal 60 Hz.
  • Les points colorés sont les électrons : ils vont du − vers le + (option « sens conventionnel » pour l'inverse). Leur vitesse suit le courant.
  • Survolez un fil ou un composant pour lire la tension, le courant et la puissance.
  • Cochez V, I, P ou R dans les propriétés d'un composant pour tracer sa courbe dans l'oscilloscope.
  • Une masse fixe la référence 0 V ; sans masse, un nœud est choisi automatiquement.
